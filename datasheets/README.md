# 元器件数据手册（自托管）

本目录收录 36 份厂商公开的电子元器件数据手册 PDF，用于 EE-INDEX 站内预览。所有 PDF 版权归原厂所有，本站仅做学习用途的镜像托管；如原厂要求下架，请联系站点维护者删除对应文件。

## 使用方式

- 站内入口：左侧目录树「EE-INDEX (C:) → 资源库 → 电子元器件数据手册」，或顶部菜单「文件 → 打开数据手册」。
- PDF 预览：详情面板「预览 PDF」按钮；预览窗口内可下载或打开原版。
- 文件路径：`datasheets/<子类>/<文件名>.pdf`，与站点根目录同级部署。
