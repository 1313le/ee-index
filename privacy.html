最后更新：2026-11-14

1. 数据与隐私

EE-INDEX 是静态资源索引，没有账号系统，也没有本站的服务器数据库。

  • 收藏、字号设置、AI 配置保存在你本机浏览器（localStorage）。清除浏览器数据会丢失。
  • 如果你配置自己的 AI API Key，Key 只保存在本机浏览器；请求由浏览器直接发送给你选择的服务商。
  • 如果使用站点公共 AI 代理，输入文字、图片、文件和录音会先发送到站点代理，再由代理转发到 AI 服务商。请不要上传个人隐私、商业机密或未授权的资料。
  • 网站会向第三方网站请求 favicon 以显示站点图标，请求不携带来源页地址。
  • 本站不接入统计脚本，不主动收集访问日志；托管平台（如 GitHub Pages）和代理平台（如 Cloudflare）可能按其自身政策记录访问信息。

项目、书单、岗位路径与薪资信息会随时间变化，请以官方和招聘方最新信息为准。

3. 无官方关联

本站是个人/社区性质的硬件学习资源索引，与 Microsoft、Windows 或任何资源网站均无官方关联。界面为早期桌面系统风格的致敬设计，不使用微软官方商标素材。

4. 使用风险

硬件设计、打样、上电、测量和量产存在电气、火灾、人身与财产风险。站内内容仅用于学习参考，不构成工程、安全或法律建议。实际项目请遵循器件手册、安规要求和所在单位流程。

5. AI 输出

AI 推荐可能不准确、过时或产生幻觉。本站会校验推荐资源/项目是否存在于目录中，但无法保证模型对技术细节的判断完全正确。涉及安全、认证、量产和选型时，请以官方资料和人工评审为准。

如果你是本站的公开部署运营者，你需要自行负责域名备案（如适用）、隐私政策、内容合规、AI 服务商条款和 API 成本控制。
